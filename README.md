## 🚀 How to Use This Kit

### Step 1: Create your GitHub Organization
```
github.com → New Organization → Name: MEW3-India
```

### Step 2: Create the `.github` repository
```bash
# This is the special repo that holds org-level files
Repository name: .github
```

### Step 3: Copy the profile README
```bash
# Place profile/README.md in:
MEW3-India/.github/profile/README.md
```

### Step 4: Add Issue Templates & Workflows
```bash
# Copy .github/ folder contents into your .github repo
MEW3-India/.github/.github/ISSUE_TEMPLATE/
MEW3-India/.github/.github/workflows/
MEW3-India/.github/.github/PULL_REQUEST_TEMPLATE.md
```

### Step 5: Add Governance Docs
```bash
# Copy docs/ to your .github repo
MEW3-India/.github/docs/
```

### Step 6: Create Individual Repositories
Create each repository listed in the structure and populate with relevant content from this kit.
